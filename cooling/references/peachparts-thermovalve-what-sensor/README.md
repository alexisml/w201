# What sensor is this? (PeachParts forum, 2002–2007)

- **Original:** <https://www.peachparts.com/shopforum/tech-help/38251-what-sensor.html>
- **Wayback Machine:** no snapshot found (2026-10-11)
- **Full copy:** kept in the private archive (whole thread as a PDF (no pictures); posts #2 and #3 explain the 50 °C thermo-vacuum valve: closed below 50 °C, passes vacuum above, used for the fuel-vapour purge (charcoal canister) system). Available on request.
- **Archived:** 2026-10-11

Posts by mbdoc and stevebfl identify the red 2-prong valve on a 1986 300E head as the thermo-vacuum valve, part `000 140 71 60` / `72 60`.
