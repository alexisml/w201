# '91 190E 2.3 part id? (PeachParts forum, 2001)

A 1991 190E 2.3 owner asks about a valve behind the thermostat housing with a broken vacuum nipple; the moderator answers it is a thermo-vacuum valve that opens at 70 °C, part `001 141 62 60`, for the emission control system.
