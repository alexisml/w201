# Mercedes-Benz service manual, group 15: Electrical system, engine (ignition)

- **Source:** factory service manual chapter supplied by the owner (download source not recorded)
- **Full copy:** kept in the private archive (87-page scanned PDF). Available on request.
- **Archived:** 2026-10-11

Jobs 15-505 to 15-547: distributor ignition (DI/EZL) and TSZ function and testing, for engines
including 102.985. Includes the R16 / R16/1 reference resistor: model 201 fixed values 220, 1300 and
2400 Ω (`000 540 22 81`, `25 81`, `26 81`), tested at the ignition control module between sensor
connector contact 3 and ground.
